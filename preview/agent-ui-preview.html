Pratinjau UI Asisten AI

Spesifikasi visual (bukan hasil build) untuk dua perubahan: tombol mode model di layar chat dengan sheet Hemat/Pintar/Cepat, dan setelan Asisten AI yang dipecah jadi tiga grup dengan satu bilah Simpan. Token warna, radius, dan tipografi mengikuti Theme.kt.

Catatan desain

  • Satu sumber kebenaran per nilai: model dipilih lewat sheet, bukan kolom teks + dropdown sekaligus.
  • Status koneksi tinggal di grup Penyedia; "Uji ulang" menguji isian yang terlihat di layar.
  • Penyedia custom dikelola dari sheet penyedia dan ikut tersimpan lewat Simpan, bukan save diam-diam.
  • Bilah Simpan/Batal sama dengan pola bagian Semester dan Pengingat; perubahan temperature/token ikut terdeteksi.
  • Semua nama model dan angka di mockup ini hanya contoh.
